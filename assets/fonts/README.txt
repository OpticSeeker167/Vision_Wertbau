VISION WERTBAU - BUNDLED FONTS

100 catalog families, plus the original reference families Inter and Cascadia Mono.
All files are genuine Google Fonts fonts and remain under their original licenses.
Each family's complete license is included as LICENSE-<family>.txt.

The catalog was checked against https://fonts.google.com/metadata/fonts.
Font bytes were retrieved from the official Google Fonts CSS service and fonts.gstatic.com.
The original full fonts were converted to WOFF2 without glyph subsetting or outline edits.
See catalog-manifest.json for every source URL, included weight, file and license.

The editor loads only the family and weight currently in use. Every selectable catalog
font is bundled locally. Google Fonts is only a recovery fallback when a local file
is missing or damaged.

Spanish uppercase/lowercase letters with accents, n-tilde, u-diaeresis, inverted
question/exclamation marks, digits and common punctuation were verified in the
font character maps. No single font is claimed to contain every Unicode symbol.

Test Sohne Breit is not redistributed. Import your own licensed font file in the
editor to use that exact family.
